Mobile Input & Keyboard Demo

A single page of input type / inputmode / enterkeyhint combinations. Open it on a phone and tap each field to see which keyboard appears.

1 The numeric numpad

inputmode="numeric" shows a digits-only keypad. Adding pattern="[0-9]*" makes older iOS honor a digits-only layout too, while type="text" avoids the quirks of type="number" (no e/+, no spinner, no scroll-wheel accidents).

Digit-only the combo you mentioned
<input type="text" inputmode="numeric" pattern="[0-9]*">
Decimal / price digits + separator
<input type="text" inputmode="decimal">
One-time code (OTP) numpad + SMS autofill
<input type="text" inputmode="numeric" autocomplete="one-time-code" maxlength="6">

6 Cheat sheet

Goal Use Keyboard
Digits only type="text" inputmode="numeric" pattern="[0-9]*" Number pad
Numbers with decimal inputmode="decimal" Number pad + .
Phone number type="tel" Phone pad
Email type="email" QWERTY + @
Website type="url" QWERTY + / .com
OTP / PIN inputmode="numeric" autocomplete="one-time-code" Number pad + SMS autofill
Date type="date" Native date picker
Why not type="number" for IDs/OTP? It accepts e, +, - and shows stepper arrows; it also can't keep a leading zero (e.g. 007). Prefer type="text" inputmode="numeric" pattern="[0-9]*" — it gives the same number pad without those problems.
